# Fotos dos membros do SACRIFICIO

Coloque nesta pasta as fotos dos membros em formato **PNG**.

## Nome dos arquivos

Use o código da casa, seguido de um underline e o número do slot, sem zeros à esquerda:

- `conquista_1.png` até `conquista_10.png`
- `guerra_11.png` até `guerra_20.png`
- `fome_21.png` até `fome_30.png`
- `morte_31.png` até `morte_40.png`

Para os gerentes, use o código da casa e o slot do gerente: `conquista_46.png`, `guerra_47.png`, `fome_48.png` e `morte_49.png`.

Para os cinco slots rotativos, use `rotativos_41.png` até `rotativos_45.png`.

Exemplo: a foto do slot 36 da casa Morte deve se chamar **`morte_36.png`**.

A página procura a imagem automaticamente quando a casa é aberta. Se o arquivo não existir, aparece um espaço reservado com a palavra FOTO. As imagens ficam no próprio GitHub Pages e não são enviadas ao Supabase.
